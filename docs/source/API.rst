=================
Package reference
=================

This page is generated by ``autosummary`` from the installed packages themselves, so it cannot
drift from the code. Three Python packages are documented here:

``freeports``
   The extraction engine. It is not a Python source tree: the package **is** the compiled PyO3
   extension built from the Rust crate. See :doc:`the Rust API <rustdoc>` for the crate itself.

``freeports_dev``
   Tooling for writing and testing a format: the ``freeports-dev`` command and the pytest plugin.

``freeports_validate``
   Methodology grants and validation of a format repository: the ``freeports-validate`` command.
