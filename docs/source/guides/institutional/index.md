# Understanding the project

This section is for reading rather than for doing. It is written for someone deciding whether this
project is worth their attention, their data, or their trust — a journalist, a researcher, an
institution weighing whether a figure from here can be cited, or simply somebody curious about what
a tool like this can honestly promise.

Nothing here assumes a technical background, and nothing here is trying to sell you anything. Where
the answer is unflattering, the page says so: a project that only publishes its strengths is asking
to be taken on faith, which is exactly what this one is built to avoid.

## The one thing worth knowing first
Every figure this project publishes about itself — how much of the code is tested, how much of the
documentation exists, how many files anyone has vouched for — is **written by a command you can
re-run**, and every generated page says which command. That is deliberate, and it is the whole
posture: {doc}`../../generated/index` is where those pages live, and none of them asks to be
believed.

If you read only two pages, read {doc}`../../overview/problem` and
{doc}`strengths-and-limits`.
