# Anything not yet placed

This page exists so that nothing has to be forced into a section it does not belong to. A subject
lands here when it is real, worth writing down, and does not yet have enough company to justify a
section of its own.

A page here is **waiting for its section to be written**, which is a normal state rather than a
failure. If you find yourself adding a third entry on the same subject, that is the signal to
promote it: see {doc}`../guides/docs/organisation`.

## Things that live outside this site
| Subject | Where |
|---|---|
| the project website | [freeports.org](https://www.freeports.org), its own repository and toolchain |
| the demo API and dashboard | `freeports-backend` and `freeports-frontend`, unrelated to the extraction side |
| the Qt desktop interface | `analysis_finance_reports_qt` — spec-first, and not built |
| licence, code of conduct, security policy | the files of the same name at the root of the repository |
